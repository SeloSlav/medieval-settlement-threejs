# Close meadow grass

`close-meadow-tuft-greener.png` is the alpha-tested albedo card used by the streamed
close-ground grass field. It runs through SeedThree's shared ground-cover
texture loader, card-clump geometry, material, wind, and instanced streaming
path. It was generated with Codex built-in image generation from the supplied
Manor Lords close-ground screenshot as a scale and silhouette reference, then
converted locally from a flat magenta chroma-key source to RGBA.

The greener version applies a restrained hue and color shift to reduce the
yellow cast while preserving a few dry tips and the source card's alpha.

Final prompt summary: a compact medieval-meadow tuft of 28–36 narrow,
individually readable olive, yellow-green, and dry straw blades; irregular
height and bend; one bottom-centre root; no flowers, broad leaves, ground,
shadow, text, logo, or watermark.
