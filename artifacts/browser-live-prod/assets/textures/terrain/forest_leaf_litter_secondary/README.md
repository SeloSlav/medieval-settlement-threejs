Secondary forest-floor PBR texture set. The independently generated albedo uses finer fragmented leaf litter to provide a motif-neutral stochastic companion to the primary texture, then is processed locally for seamless tiling; normal, roughness, AO, and height were derived locally by scripts/derive_pbr_maps.py. Runtime color is packed with the primary litter, dry grass, and snow in manor_grass_dry/snow_leaf_albedo_atlas.png.
