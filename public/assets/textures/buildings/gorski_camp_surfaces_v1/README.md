# Gorski camp surfaces v1

This versioned PBR set contains the stitched, hair-off hide surface used by the reusable hunter processing shelter. The source base-color image was generated with OpenAI's built-in image-generation workflow, then made periodic and converted into deterministic OpenGL normal and packed roughness/metalness/AO/height maps by `scripts/prepareCampHideMaterial.mjs`.

The texture represents approximately 1.6 m across and is intended for metric UV repetition. It is a construction surface, not a harvested-game or inventory-state prop.
