Secondary forest leaf-litter PBR texture set. The albedo was generated with Codex built-in image generation as an independent, motif-restrained companion to the primary forest floor, then processed locally for seamless tiling; normal, roughness, AO, and height were derived locally by scripts/derive_pbr_maps.py. Runtime color is packed with the primary litter, dry grass, and snow in manor_grass_dry/snow_leaf_albedo_atlas.png.
