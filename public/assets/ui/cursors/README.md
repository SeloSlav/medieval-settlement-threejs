# Medieval cursors

Generated with the built-in imagegen tool. `medieval-pointer-source.png` preserves the original alpha artwork. `medieval-pointer.png` is the 40 × 40 runtime cursor, with a 2,2 hotspot. Rebuild the set using `scripts/prepareMedievalCursor.ps1` on PowerShell 7 / .NET 10 for Windows.

## Generation prompt

Use case: stylized-concept
Asset type: production mouse cursor PNG for a grounded medieval settlement strategy game.
Primary request: One elegant medieval arrow pointer on a genuinely transparent alpha background. A compact familiar mouse-arrow silhouette aimed diagonally toward upper left, forged pale ivory silver metal with a restrained aged brass bevel and dark brown outline. Broad triangular arrow head tapering to an exact sharp hotspot tip, a short integrated stem toward lower right; no sword crossguard. Handcrafted medieval feel, lightly weathered, very clear silhouette readable at 32 to 40 pixels. Flat orthographic UI asset, crisp edges, subtle material shading and high contrast on dark grass or pale menus.
Composition: Single isolated pointer, large in a square canvas, small transparent margin around silhouette. Its upper-left tip is the topmost and leftmost point.
Constraints: Actual transparent background, no checkerboard rendered into image, no scene, no text, no lettering, no logos, no watermark, no extra icons, no glow, no cast shadow outside the outline. Output PNG.

## Pan and orbit companions

`medieval-pan.png` and `medieval-orbit.png` are 40 × 40 transparent PNGs with centered 20,20 hotspots. The `-source.png` siblings retain the generated artwork. Both use the pointer above as their material reference and were generated with the built-in imagegen tool. The final alpha-extraction pass removes the initially painted checkerboard. Generate only the companions with `./scripts/prepareMedievalCursor.ps1 -Cursors pan,orbit`.
