# Dedicated development icons

These transparent raster emblems are reserved for the development wheel. They
replace building-card images whose parchment backplates could bleed outside the
circular development seals.

- `carters-guild.png`: iron-tyred cart wheel, carter's mallet, hemp rope.
- `chartered-markets.png`: merchant balance and sealed market charter.
- `watch-fires.png`: iron beacon basket and warning bell.
- `coppice-craft.png`: hazel coppice stool, billhook, bundled poles.
- `river-wardens.png`: river trout and woven willow fish trap.

Generated with the built-in image generator as isolated, historically
plausible game icons. Source generation outputs remain in the Codex generated
images directory; the 512 px project copies are the runtime assets.
