# Development branch woodcuts

Four transparent decorative vignettes used beneath the development wheel. The existing CSS conic gradient owns the quadrant colors; these PNGs contribute subdued engraving marks only.

- `land-harvest-woodcut.png` — upland ploughing, grain, and orchard
- `craft-trade-woodcut.png` — smithing, wheelwright work, and road trade
- `hearth-watch-woodcut.png` — mountain homes, communal hearth, and watch fire
- `woodland-waters-woodcut.png` — coppice work, forest, stream, fish, and deer

All files are 512 × 341 RGBA PNGs, downsampled from the generated masters for runtime use.
